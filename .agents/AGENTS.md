# Custom Rules for TESIS Simulation Workspace

## LaTeX File Safety
* **Preserve User Changes:** Before making any programmatical, automated, or replacement edits to any `.tex` file in `TESIS_LATEX/`, always verify if there are current unsaved or local changes made by the user. 
* **Back Up Prior to Editing:** Save or copy the current state of any `.tex` file to a temporary backup (such as a git stash, a temporary backup file, or by checking the status) to prevent any manual edits from being overwritten or lost during automated operations.
